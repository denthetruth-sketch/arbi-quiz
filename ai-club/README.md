# ИИ-клуб — вопросы залу между докладами

Двенадцать экранов на телевизоре:

цитата Пикассо → имя → чем занимаешься → где ты с ИИ → цитата Шеннона →
источники данных → доклад 1 → идея продукта → доклад 2 → доля задач для ИИ → доклад 3 → цитата Брэдбери.

На экранах с вопросами слева в реальном времени появляются ответы, справа — QR-код и счётчик ответивших.
QR один на все вопросы: телефон сам показывает тот вопрос, который сейчас на экране.

| Файл | Что это |
|---|---|
| `screen.html` | Экран на телевизор. Открыть на ноутбуке, подключённом к ТВ. |
| `answer.html` | Страница для телефона — сюда ведёт QR. |
| `config.js` | Вопросы, названия докладов, имена докладчиков. **Правится только он.** |
| `screen.html?demo` | Демо с выдуманными ответами: посмотреть вид, в базу ничего не пишет. |

Ответы хранятся в той же базе Firebase, что и квиз ARBI (`../firebase-config.js`), в отдельной ветке `aiclub/`.

## Перед событием — один раз

**1. Открыть базе запись для `aiclub`.** Firebase Console → Realtime Database → Rules:

```json
{
  "rules": {
    "aiclub": { ".read": true, ".write": true }
  }
}
```

Остальная база (квиз ARBI) при этом остаётся закрытой. После события поменяйте `true` на `false`.

**2. Вписать докладчиков** в `config.js`: `title`, `speaker`, при желании `role`.

**3. Сайт должен быть в ветке `main`** — GitHub Pages публикует только её. Адрес экрана:
`https://<логин>.github.io/arbi-quiz/ai-club/screen.html`

## Как вести

- `→`, пробел или кликер — следующий экран, `←` — назад, `Home` — в самое начало, `1`–`9` — сразу на экран с этим номером.
- `F` — полный экран.
- Шевельните мышью — в правом нижнем углу появится меню: стрелки, «Очистить ответы» (после репетиции!), «Вернуть скрытые».
- **Двойной клик по ответу на экране скрывает его** — на случай шуток не по теме.
- Перезагрузка экрана ничего не ломает: открытый экран и ответы хранятся в базе.

Ответы:
- **Имя — облако.** Один ответ с телефона, его можно исправить. Одинаковые имена растут.
- **Чем занимаешься — выбор.** Кнопки на телефоне, на экране столбики с числом и процентом, лидер подсвечен.
- **Где ты с ИИ — шкала.** Пять ступеней: сколько человек на каждой и метка «зал в среднем».
- **Источники данных — облако.** Одинаковые ответы склеиваются (регистр и «ё» не важны) и растут; цифра рядом — сколько раз назвали.
  «CRM, Excel» с одного телефона — это два источника.
- **Идея продукта — карточки.** Новые сверху. Если идей очень много, шрифт уменьшается, самые старые уходят за нижний край.
- **Доля задач для ИИ — проценты.** Один ответ с телефона (можно поменять). На экране среднее и распределение по десяткам.

«Сколько человек ответило» считается по телефонам, а не по ответам: один человек с тремя ответами — один.

## Репетиция

Откройте `screen.html?room=test` и отсканируйте QR с него — всё уйдёт в отдельную комнату `test`,
боевые ответы останутся чистыми.
